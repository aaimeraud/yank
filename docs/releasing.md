# Releasing

Versions follow [SemVer](https://semver.org). The changelog is generated by
[git-cliff](https://git-cliff.org) from [Conventional Commits](https://www.conventionalcommits.org)
(`type(scope): summary`), so the commit history is the source of truth: a
commit that is not conventional does not appear in `CHANGELOG.md`.

Tools: `brew install git-cliff uv`.

## Cut a release

```bash
git cliff --unreleased                  # read what would ship
uv run scripts/release.py bump --auto   # or: bump 0.2.0
```

Under GitButler, HEAD is `gitbutler/workspace`, which merges every applied
branch. Pass the branch you are releasing (`--ref daniel/release-prep`) so the
changelog leaves the other branches' commits out.

`bump` rewrites the version in `package.json`, `src-tauri/Cargo.toml`,
`src-tauri/Cargo.lock` and `src-tauri/tauri.conf.json`, regenerates
`CHANGELOG.md`, and prints the commit, tag and push commands. It never commits
or pushes itself.

`--auto` lets git-cliff pick the version from the commits since the last tag.
Before 1.0 a `feat` bumps the patch and a breaking change (`feat!:` or a
`BREAKING CHANGE:` footer) bumps the minor (`[bump]` in `cliff.toml`).

Pushing the `vX.Y.Z` tag runs `.github/workflows/release.yml`: it checks the
tag matches the app version, builds the app for Apple Silicon and Intel, and
publishes a GitHub release with that version's changelog section as notes.

The build is **unsigned**. On first launch macOS refuses it; right-click the
app, choose Open, then Open again. Signing and notarization need an Apple
Developer ID and are not set up.

## Checks

| Command | What it checks |
| --- | --- |
| `uv run scripts/release.py check` | The four version fields agree |
| `uv run scripts/test_release.py` | The bump script itself |
| `git cliff --unreleased` | Changelog preview, no file written |

CI (`.github/workflows/ci.yml`) runs all of these plus `bun run check` on every
push to `main` and every pull request.
